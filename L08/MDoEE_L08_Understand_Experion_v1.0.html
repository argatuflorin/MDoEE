Experion in one picture

Experion® is the process automation platform of Honeywell. The same family is sold in several sizes. In this laboratory we use the name Experion PKS (Process Knowledge System).

Sources: [S1] Honeywell, Experion LX; [S8] Experion HS brochure; [S9] C300 controller; [S5] Experion and ControlEdge PLC white paper.

Key facts (from Honeywell documentation)

Origin. Honeywell states that it pioneered the Distributed Control System (DCS) in the 1970s. [S10]
Unified architecture. Experion PKS integrates process control, safety systems and advanced applications under one architecture. [S10]
Experion LX is a DCS built on Experion PKS technology. It uses Fault Tolerant Ethernet (FTE) and the tools Control Builder, Quick Builder and the HMIWeb Solution Pack. [S1]
Experion HS is listed by Honeywell among its SCADA products. It integrates with the ControlEdge PLC and RTU. [S8]
C300 is described by Honeywell as the heart of the Experion control system. [S9]

Experion PKS architecture · click a block

Simplified didactic view. Not every installation has every block: Honeywell states that the architecture is highly scalable and not all nodes are required [S6].

Selected block

FTE · two parallel trees in one network · click a link to break it

Each FTE node has two network ports, one to a switch in tree A and one to a switch in tree B. The top-level switches of the two trees are joined, so A and B form one network [S3][S4].

Communication paths server ↔ station

Working paths: 4 / 4 · communication OK

Why it matters. Honeywell gives four communication paths between two FTE nodes [S4]. The network tolerates all single faults and many multiple faults. Switchover takes under one second, compared with over 30 seconds for conventional two-network redundancy [S3].
Documented example. With channel A broken on node 1 and channel B broken on node 2, the nodes still communicate from node 1 channel B to node 2 channel A, through the crossover [S4].

Anatomy of a point · PMP_I (pump current)

An Experion point has a composite data structure: one point represents several field values [S8]. Below, one simulated analog point. The values change when the simulation runs.

0.0PV · process value (A)
0.0SP · setpoint (A)
0.0OP · output (%)
AUTOMODE

Didactic simulation: a PI-type loop drives OP so that PV follows SP. In MAN the operator owns OP and PV drifts. PV/SP/OP are general process-control terms used throughout the Experion displays.

ControlEdge PLC → Experion, automatically

PLC variables are configured automatically in the Experion point database. Experion Analog and Status points are generated directly from the PLC program, so nothing is entered twice [S5].

Summary (breviar)

  • Experion PKS = Honeywell's DCS platform; LX = DCS built on PKS; HS = SCADA product of the family.
  • Layers: Stations (Console, Flex) → Server (can be redundant) → FTE network → controllers (C300, ControlEdge PLC) → I/O → field.
  • FTE: one network made of two parallel switch trees A and B joined at the top; each node has two ports → 4 paths between two FTE nodes: A–A, B–B, A→B, B→A (the last two through the crossover).
  • A path works only if every link on it works. Communication is lost only when all 4 paths are broken.
  • FTE switchover: under 1 s; conventional dual-network redundancy: over 30 s.
  • Engineering: Control Builder (strategies, points), Quick Builder (points, controllers, stations, printers), HMIWeb Display Builder (operator graphics), SIM-C200 (simulation without hardware).
  • A point is a composite structure: PV, SP, OP, MODE, alarm limits…
  • ControlEdge PLC variables → Experion Analog/Status points automatically over OPC UA.
  • EB110: Hyper-V host, server E0001, Flex stations F0001–F0011 over RDP, users operatork / engineerk; demo service stops every 300 min.
